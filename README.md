## Paid Industry Certifications (Cloud & DevOps)

|---|---|---|---|---|---|---|
| AWS Certified Cloud Practitioner | [aws.amazon.com/certification](https://aws.amazon.com/certification/certified-cloud-practitioner/) | AWS | Foundational | $100 | 3 years | Absolute beginners to cloud, non-technical/PM roles too |
| AWS Certified Solutions Architect – Associate (SAA-C03) | [aws.amazon.com/certification](https://aws.amazon.com/certification/certified-solutions-architect-associate/) | AWS | Associate | $150 | 3 years | The single most in-demand AWS cert; strong resume signal for SWE/cloud roles |
| AWS Certified Developer – Associate | [aws.amazon.com/certification](https://aws.amazon.com/certification/certified-developer-associate/) | AWS | Associate | $150 | 3 years | Developers building/deploying on AWS (Lambda, DynamoDB, CI/CD) |
| AWS Certified SysOps Administrator – Associate | [aws.amazon.com/certification](https://aws.amazon.com/certification/certified-sysops-admin-associate/) | AWS | Associate | $150 | 3 years | Ops/SRE-leaning roles, monitoring & deployment |
| AWS Certified Solutions Architect – Professional (SAP-C02) | [aws.amazon.com/certification](https://aws.amazon.com/certification/certified-solutions-architect-professional/) | AWS | Professional | $300 | 3 years | Senior/staff cloud architecture roles; expects Associate-level knowledge first |
| AWS Certified Machine Learning Engineer – Associate | [aws.amazon.com/certification](https://aws.amazon.com/certification/certified-machine-learning-engineer-associate/) | AWS | Associate | $150 | 3 years | ML engineers deploying models on AWS infrastructure |
| Microsoft Azure Fundamentals (AZ-900) | [learn.microsoft.com/credentials](https://learn.microsoft.com/en-us/credentials/certifications/azure-fundamentals/) | Microsoft | Fundamentals | $99 | Does not expire | No-cloud-background beginners; cheapest, fastest Azure entry point |
| Microsoft Azure Administrator (AZ-104) | [learn.microsoft.com/credentials](https://learn.microsoft.com/en-us/credentials/certifications/azure-administrator/) | Microsoft | Associate | $165 | 1 year (free renewal assessment) | The most job-listing-requested Azure cert; identity, storage, compute, networking |
| Microsoft Azure Developer Associate (AZ-204) | [learn.microsoft.com/credentials](https://learn.microsoft.com/en-us/credentials/certifications/azure-developer/) | Microsoft | Associate | $165 | 1 year (free renewal assessment) | Developers building/deploying Azure-hosted apps (App Service, Functions) |
| Microsoft Azure Solutions Architect Expert (AZ-305) | [learn.microsoft.com/credentials](https://learn.microsoft.com/en-us/credentials/certifications/azure-solutions-architect/) | Microsoft | Expert | $165 | 1 year (free renewal assessment) | Senior architecture roles on Azure; expects AZ-104 knowledge |
| Microsoft DevOps Engineer Expert (AZ-400) | [learn.microsoft.com/credentials](https://learn.microsoft.com/en-us/credentials/certifications/devops-engineer/) | Microsoft | Expert | $165 | 1 year (free renewal assessment) | CI/CD pipelines, release management on Azure |
| Google Cloud Digital Leader | [cloud.google.com/certification](https://cloud.google.com/learn/certification/cloud-digital-leader) | Google Cloud | Foundational | $99 | 3 years | Non-technical/beginner entry point into the GCP ecosystem |
| Google Cloud Associate Cloud Engineer | [cloud.google.com/certification](https://cloud.google.com/learn/certification/cloud-engineer) | Google Cloud | Associate | $125 | 3 years | Hands-on GCP deployment and management skills |
| Google Cloud Professional Cloud Architect | [cloud.google.com/certification](https://cloud.google.com/learn/certification/cloud-architect) | Google Cloud | Professional | $200 | 2 years | One of the highest-paying cloud certs industry-wide; case-study heavy exam |
| CKA — Certified Kubernetes Administrator | [training.linuxfoundation.org](https://training.linuxfoundation.org/certification/certified-kubernetes-administrator-cka/) | Linux Foundation / CNCF | Professional | $445 | 2 years (1 free retake included) | Vendor-neutral, hands-on Kubernetes cluster administration — highly respected for DevOps/SRE roles |
| CKAD — Certified Kubernetes Application Developer | [training.linuxfoundation.org](https://training.linuxfoundation.org/certification/certified-kubernetes-application-developer/) | Linux Foundation / CNCF | Professional | $445 | 2 years (1 free retake included) | Developers deploying/managing applications on Kubernetes |
 
> 💡 **Cost-saving tip:** AWS gives a 50% discount voucher on your next exam after passing one — stacking Cloud Practitioner → Associate → Professional costs meaningfully less than paying full price for each. Azure Fundamentals-level exams never expire, making AZ-900 a low-risk first cert if you're new to cloud. Prices vary by country (India pricing is typically lower in INR) — always confirm on the vendor's official page before paying.
